# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
* リモートリポジトリは「web上の保存場所」
* ローカルリポジトリは「自身のPC内の保存場所」


## プッシュとマージの違いは何でしょうか？
* プッシュは、ローカルのコミット（変更内容）をリモートに反映させること。
* マージは、他のブランチのコミットを、反映させたいブランチに反映させること。


## コミットとプッシュの違い
* コミットは、変更を保存して名前を付ける作業のこと。
* プッシュはローカルのコミットをリモートに反映させること。そのため、コミットの後にプッシュを行う。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
* 「どんな変更を行ったのか」が、だれが見ても分かるように書いてあるのが最適。



## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
* 第三者のレビューがあるか否かの違い。
* ローカルでマージする場合は、第三者のレビューがないため、ミスの見落としの可能性が高い。
* プルリクエストでのマージでは、第三者のレビュー後のマージのため、ミスが発覚してもメイン（マスター）に反映させる前に未然に防ぐことができる。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
以下の３通りから変更を取り込む
1. 先にマージされた変更だけを残す
2. 後からマージする変更だけを残す
3. 両方の変更を組み合わせて残す
