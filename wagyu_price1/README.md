# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
* リモートリポジトリ→web上の場所で他人と共有できる。
* ローカルリポジトリ→自身のPC内の保存場所。
* リポジトリ→ファイルやプログラムを保存する領域。



## プッシュとマージの違いは何でしょうか？
* プッシュは、ローカルのコミット（変更内容）をリモートに反映させること。
* マージは、異なるブランチで行われた変更を一つに統合すること。


## コミットとプッシュの違い
* コミットは、変更内容を保存し、それに名前を付けること。
* プッシュは、ローカルで行ったコミットをリモートに反映させること。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
* どこをなぜ、どのように変更したのかを簡潔に、誰が見ても分かりやすく書くことが最適。


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
* ローカルでマージするフローは、第三者のチェックができない。そのためリモートにマージする際は、より慎重に行わなければならない。
* プルリクエストでマージするフローは第三者のチェックができる。そのため、プルリクエストの時点でミスが発覚しても、反映前に未然に防ぐことができる。



## コンフリクトを起こしてしまった場合、どう対処すべきですか？
以下の３通りの対処方法がある。

1. 先にマージされた変更だけを残す
2. 後からマージする変更だけを残す
3. 両方の変更を組み合わせて残す

修正が終わったら通常通りファイルをコミットする。
